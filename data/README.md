## Data Source

This project uses the **USA Real Estate Dataset** by Ahmed Shahriar Sakib, originally published on Kaggle.

Dataset:
https://www.kaggle.com/datasets/ahmedshahriarsakib/usa-real-estate-dataset

The dataset contains more than 2.2 million U.S. property listings, including fields such as price, bedrooms, bathrooms, lot size, city, state, ZIP code, house size, property status, and previous sold date.

The original `realtor-data.zip.csv` file is not included in this repository due to GitHub file-size limitations. To run the notebooks locally, download the dataset from Kaggle and place it in the `data/` directory.
